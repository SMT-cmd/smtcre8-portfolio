EDUCATION / PROJECT CASE STUDY

Unileh Print Hub.

A campus printing and student-services platform designed around how students actually submit, pay for and collect documents.

Explore product website ↗Request something similar ↗

THE PRODUCT TODAY

Hosted campus service · evolving operations

The repository includes a custom-domain configuration and student/admin flows. Printing, payment and pickup outcomes depend on active service operation, not just deployed code.

DISCIPLINE

Student services

Built around practical needs, with ongoing refinements where needed.

01 / THE STARTING POINT

Why I started it.

A student should not need a confusing chain of messages to print an assignment or get assistance with routine school portal processes.

02 / THE IDEA

How the solution took shape.

A simple journey: upload a document, choose printing options, review the cost, submit, and know when the order is ready for collection.

03 / THE EXPERIENCE

What the product includes.

  • Student PDF, Word-document and image uploads for print requests.
  • Black-and-white or colour options, copy counts and estimated pricing.
  • Portal assistance, campus announcements and partner/service discovery.
  • Administrative order tracking, collection states and customer communication workflows.

04 / THE BUILD

How it works.

A web application using client-side HTML, CSS and JavaScript with Firebase authentication/data work and Appwrite storage integration described in the repository. A PWA manifest and service-worker approach support installability; production integrations require operational setup.

05 / MY CONTRIBUTION

The work behind it.

Campus-service product planning, student workflow design and administrative operations experience.
