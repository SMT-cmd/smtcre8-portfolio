MY-RP.

THE PRODUCT TODAY

Public playable build · continuing development

The repository documents a live Render deployment and tested application foundations. This is an evolving build, not the complete nationwide simulation vision.

DISCIPLINE

Interactive simulation

Built around practical needs, with ongoing refinements where needed.

01 / THE STARTING POINT

Why I started it.

What would an interactive Nigerian society look like if everyday decisions, local economies, education, housing and civic life formed one connected world? MY-RP began with that question.

02 / THE IDEA

How the solution took shape.

The long-term direction is an explorable simulation of life across Nigeria. Implementation proceeds through world interactions, durable identities and rule-driven systems before expanding toward the entire planned national map.

03 / THE EXPERIENCE

What the product includes.

  • Interactive city and home environments with movement and object selection.
  • Citizen sessions, registration and persistent state, with session-resume protections.
  • Housing and furniture placement concepts with interactive controls.
  • Economy, education, civic participation and wider multiplayer systems as progressive build areas.

04 / THE BUILD

How it works.

A server-backed interactive web game with client rendering, Supabase-linked identity/data components and documented test coverage. Render hosting is documented. Some nationwide systems, mobile/GPU performance gates and complete gameplay remain open.

05 / MY CONTRIBUTION

The work behind it.

World vision, simulation rules, system design, environment planning and implementation/testing oversight.
