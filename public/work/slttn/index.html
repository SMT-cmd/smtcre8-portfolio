THE PROJECT TODAY

Public project · continuing enhancement

This repository is the main website and library experience for SLT Trade Hub—not a separate trading company.

DISCIPLINE

Website and books

01 / THE STARTING POINT

Why I created it.

The SLT Trade Hub brand needed one reliable public place to share trading knowledge, organise books and guide learners toward a reading experience.

02 / THE DIRECTION

The design approach.

Build a navigable educational website with a searchable catalogue, book detail pages, reader flows and administration for learning materials.

03 / INSIDE THE PROJECT

What the experience includes.

  • Searchable library, book-category filters and individual title pages.
  • Online reader access and documented pricing/access rules.
  • Account, community, authoring and administration interfaces.
  • Public metadata for published books and cover graphics.

04 / IMPLEMENTATION

What powers it.

A TypeScript/React application with TanStack Router and a database-backed book catalogue. It maintains a distinction between publicly published titles and drafts. The planned portfolio sync reads only that public metadata.

05 / MY CONTRIBUTION

My role.

Product ownership, web architecture, teaching-content direction and digital library experience.
