THE PRODUCT TODAY

Built application · release improvements

The repository contains a complete routed Next.js application and automated test evidence. A Vercel project and deployment exist; full account, device and notification acceptance is still in progress.

DISCIPLINE

Fitness application

Built around practical needs, with ongoing refinements where needed.

01 / THE STARTING POINT

Why I started it.

Consistency is often the hardest part of exercise. A useful fitness tool should help someone choose an achievable routine, complete sessions and recognize progress without needing multiple apps.

02 / THE IDEA

How the solution took shape.

HomeFit brings planning, exercises, progress and social accountability together. Its direction is practical: start with reachable goals, record sessions accurately, and let friends make training more motivating.

03 / THE EXPERIENCE

What the product includes.

  • Goal-based weekly plans, workout catalogue, timed exercises and recorded sessions.
  • A personal dashboard with progress history, activity charts, nutrition and exercise guidance.
  • Opt-in community leaderboards, workout partner invitations and shared challenges.
  • Account settings, fitness preferences, reminders and profile imagery.

04 / THE BUILD

How it works.

A React and TypeScript application using Next.js and Supabase. The project documents local browser regression coverage and data migrations. Background reminders after all tabs close, cross-device state and production authentication require dedicated validation; in-app reminders are a separate capability.

05 / MY CONTRIBUTION

The work behind it.

Product concept, user-flow design, app modernization, frontend and backend direction, accessible responsive quality checks.
